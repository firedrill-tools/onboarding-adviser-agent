# Qualified standalone contract

Node.js 22+; actual AI SDK **7.0.141**, @ai-sdk/openai **4.0.94**, @ai-sdk/anthropic **4.0.80**, Zod **4.6.7**. package-lock.json resolves transitive dependencies. The previous Node >=20 declaration did not match provider packages' >=22 requirement and is corrected.

The actual generateText/Output.object path is retained. Both native adapters originally accepted schema-valid partial and absent-completion output. A supported provider fetch option now records decoded JSON before SDK validation and requires completed OpenAI Responses or Anthropic end_turn plain text. SDK finishReason/one-step/no-tool checks apply before state publication. JSON Responses/Messages is qualified; streaming, extended thinking, provider tools, remote conversations and external onboarding actions are not.

Execution has maxRetries=0, maxOutputTokens=2048, one prepared POST and at most 120 seconds overall. Request JSON is checked before dispatch (1 MiB); response readers stop/cancel at 1 MiB decoded bytes. Captured hash is distinct from a full body hash for truncated responses. This is not a transport-level compressed-byte limit. Explicit keys/models/endpoints avoid an account/model guess. HTTPS or loopback HTTP is permitted, redirects fail, and only the expected endpoint/method is accepted. A public injected fetch must honor AbortSignal like standard fetch. The application owns per-turn cancellation and response reader cleanup, while the caller/runtime owns its fetch implementation/pool; no global dispatcher is replaced or closed.

Native evidence preserves raw provider body, independent reported input/output/total counts, IDs/completion, SDK-normalized usage separately, errors and state commit truth. Missing/negative/noninteger/unsafe counts are null; zero remains zero. Anthropic input/output are available while total remains unknown; no sum or billing is invented. SDK schema failures can prevent a commit even when HTTP completion passed, while original measurements survive. Injected generators have no native provider measurements. Schema/phrase checks are not semantic entailment or successful onboarding evaluation.

Stored sessions have strict schema/version, UUID, five nullable fields, provenance tied to exact user phrases, revision/history agreement, 40-turn/80-message/2-MiB bounds. Legacy v0.1 fields gain defaults only in memory/on a successful next save. Owner locks exclude cooperative writers across Node processes; exact initial bytes and revision/identity checks precede private fsynced atomic publication. A hard kill leaves an inspectable owner lock and requires manual recovery; no expiry or silent takeover is implemented. Uncooperative external editors do not participate in the lock protocol. Different sessions can execute independently.

Source state, raw generated turn, request/response, commit phase and receipt completion are separate facts. A post-save receipt/cleanup failure never implies rollback. An uncertain/committed publication requires inspection before retry; no automatic second turn runs. Recording failure is sticky for the run and stops later publication; if final persistence fails, the last on-disk receipt may remain running while the exception carries failed in-memory evidence. Source state itself is authoritative for whether a turn exists.

Ten hash-bound version-1 cases include a coherent 18-turn busy session and a 40-turn boundary. Prior messages are explicitly synthetic_human_authored, never prior model execution evidence. Current initial-state SHA and declared dataset identity remain in receipts; mutated working sessions need not match the initial manifest hash. Initialization validates all manifest hashes/identities/path confinement and copies exclusively at 0600. Model input has current requirements/recent messages/latest user text, excluding manifest focus or identity metadata.

Actual child CLI tests exercise native HTTP, successive turns, failed/missing completion, one 503 attempt and SIGINT/SIGTERM cleanup. macOS/Linux signals and locked tar source archives are qualified; Windows signal/tar behavior is unqualified. The archive includes package-lock.json and is installed with npm ci outside checkout; ordinary npm pack does not provide this lock-bound source artifact.

Live OpenAI/Anthropic judgment, provider retention/billing, new released Firedrill persisted scenarios and public license/publication remain external gates.
